# Real-Time Surface Primer Tracking System (YOLOv11)

This project focuses on developing a **real-time defect detection and surface primer tracking system** using state-of-the-art deep learning techniques. The system was designed to improve quality inspection efficiency and automate reporting workflows in an industrial setting.

> ⚠️ Note: Due to internship guidelines, specific datasets, internal images, and model architecture details cannot be shared publicly.

---

## 🔹 Project Overview

The project aimed to detect and track surface primer application defects in real time, helping reduce manual inspection efforts and ensure high-quality standards.

Key goals:

* Detect incomplete or incorrect primer coverage in real-time
* Automate daily reporting of defect analysis
* Improve the speed and accuracy of defect resolution

---

## ⚙️ Features

* **Real-time defect detection** using YOLOv11
* **Interactive GUI** for visualization and control
* **Automated daily reporting**, significantly reducing manual effort
* Pre-processing and model optimization techniques to enhance accuracy
* Ensures high compliance with quality standards

---

## 📈 Achievements

* Achieved **95%+ detection accuracy** for coverage defects
* Reduced manual inspection time by **40%**
* Improved defect resolution speed by **30%**
* Ensured **98% compliance** with quality standards

## 🧠 Technical Highlights

* Advanced **pre-processing techniques** to improve model robustness
* **Customized YOLOv11 architecture** to handle challenging industrial images

## 🚀 How It Works (High-Level)

1. **Data Preprocessing:** Images are pre-processed to enhance visibility and highlight potential defects.
2. **Model Inference:** YOLOv11 detects primer coverage defects in real-time video streams or images.
3. **GUI & Reporting:** The GUI visualizes detections and automatically generates reports summarizing coverage and defect statistics.
